# RESTAURANT MANAGEMENT SYSTEM

## Project Description

The Restaurant Management System is a web-based application
developed to help manage restaurant operations efficiently.

The system provides a centralized platform for managing restaurant
categories, menus, menu items, waiters, tables, waiter tablee, orders and order details.

## Main Features

- Dashboard
- Category Management
- Menu Management
- Menu Item Management
- Waiter Management
- Table Management
- Waiter-Tablee Management
- Order Management
- Order Details

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Python
- Django

## Purpose of the System

The system is designed to simplify restaurant operations by
providing an organized way to manage restaurant information,
tables, menus and customer orders.Maintain menu categories, prices and availability; record orders and their quantities; and manage table status, waiter details and table assignments. The dashboard brings these records together and highlights today's sales from confirmed orders and confirmed-order history.
